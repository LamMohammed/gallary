# قاعدة البيانات (Supabase)

شغّل الملفات **بالترتيب** من Supabase → SQL Editor. لو القاعدة شغالة بالفعل عندك،
شغّل بس اللي لسه ما اتشغلش (أغلب الظن: 004 و 005 و 006 و 007).

| الملف | بيعمل إيه |
|------|-----------|
| `001_schema.sql` | الجداول + سياسات القراءة + مخزن الصور |
| `002_seed.sql` | بيانات المنتجات الأولية |
| `003_sort_and_visits.sql` | ترتيب المنتجات + جدول الزيارات |
| `004_security.sql` | **الأمان**: أدمن محدد، RPC بحد معدّل، قيود الصور |
| `005_content_cleanup.sql` | تنظيف الأوصاف + مسارات الصور الجديدة |
| `007_variants_v2.sql` | **لون ومقاس معًا** + النسخة من غير صورة (بتاخد صورة المنتج الأساسي) |
| `006_variants_and_settings.sql` | **نسخ المنتج** (ألوان/مقاسات) + **إعدادات الاسم والرقم** القابلة للتعديل من لوحة الإدارة |

> **مهم:** شغّل `004_security.sql` **قبل** رفع النسخة الجديدة من الموقع، لأن الموقع بقى
> يسجّل الزيارات والاستفسارات عن طريق الدالتين `log_visit` و `log_inquiry`.
