# الألوان والمقاسات (نسخ المنتج) — v2

## بنية البيانات
```
منتج أساسي (family)            ← الاسم + الوصف + التصنيف + الصورة الأساسية
 └─ نسخة (variant) × N         ← كود (إلزامي وفريد) + لون؟ + مقاس؟ + صورة؟
```
- كل نسخة ليها **كودها الخاص**، ولونها ومقاسها لو معروفين، وصورتها لو ليها صورة.
- لو النسخة **من غير صورة** بتستخدم صورة المنتج الأساسي تلقائيًا.
- اللي مش معروف **بيتساب فاضي** ومش بيتعرض (مفيش لون أو مقاس بيتخمّن).
- في القاعدة: كل نسخة صف في `products`، والنسخ اللي ليها نفس `group_id` هي منتج واحد.
  الكتالوج الاحتياطي في `site/js/catalog.js` مكتوب بنفس الفكرة (`CATALOG_FAMILIES`).

## إزاي الموقع بيقرّر شكل الاختيار (من البيانات نفسها)
| الاختلاف بين النسخ | اللي بيظهر للعميل |
|---|---|
| ألوان مختلفة | دوائر ألوان على البطاقة + صف صور مصغّرة بأسماء الألوان في المودال |
| مقاسات مختلفة | أزرار مقاسات صغيرة متجاورة |
| لون ومقاس معًا | دوائر الألوان + أزرار المقاسات مع بعض |

لو العميل اختار لون مش متاح بنفس المقاس الحالي، الموقع بيروح لأقرب نسخة متاحة ويحدّث قائمة المقاس.
الكمية بتتحفظ لكل نسخة لوحدها.

## من لوحة الإدارة
1. أضيفي المنتج الأساسي (صورة + بياناته).
2. «إضافة منتج» ← «نسخة من» ← اختاري الأساسي (الاسم والوصف بيتعبّوا).
3. اختاري «الاختلاف بين النسخ»، واكتبي اللون و/أو المقاس **الحقيقيين**، وارفعي صورة لو ليها صورة.
4. لتحويل منتجات موجودة: افتحي المنتج (تعديل) ← «نسخة من».

### إضافة كل الألوان والمقاسات مرة واحدة
لوحة الإدارة ← «ألوان ومقاسات» (أو زرار 🎨 جنب المنتج): اختاري الأساسي، اكتبي الألوان (سطر لكل لون، وممكن `أحمر #C0392B`) والمقاسات (سطر لكل مقاس)، واضغطي «توليد النسخ».
ارفعي صورة لكل لون (بتتطبّق على كل مقاساته) و/أو لكل مقاس، وراجعي الأكواد، وبعدين «حفظ النسخ».
لو اتنين مع بعض بتتعمل كل التركيبات. التركيبة المطابقة للأساسي بتتعلّم ✗ تلقائيًا.

### ترتيب المنتجات
في «المنتجات» اسحبي المسكة ⋮⋮ لأي مكان (أو استخدمي الأسهم). الأساسي في المجموعة = أول نسخة في الترتيب، فمتحطّيش نسخة فوق الأساسي.

## رسالة واتساب
بتشمل: اسم المنتج، الكود، الخامة، **اللون (لو حقيقي)**، **المقاس (لو موجود)**، الكمية —
حسب النسخة المختارة فعلًا. اللون العام التلقائي («ذهبي» للذهبي) ما بيتبعتش كلون.

## فحص بياناتك الحقيقية
`python tools/audit_catalog.py --live --out docs/DATA-AUDIT.md`
بيطلّع المشاكل والمرشّحين للتجميع **من غير ما يدمج حاجة**. بعد ما تؤكدي المجموعات اكتبي `groups.json`
(`[{"group":"x","by":"color","members":["g1","g2"]}]`) وشغّلي `python tools/audit_catalog.py --groups groups.json`
فيطبع أوامر SQL تلصقيها في Supabase.

> لازم `database/006` و `007` يكونوا اتشغلوا. قبلهم الموقع بيشتغل عادي والنسخ بتظهر منتجات منفصلة.
