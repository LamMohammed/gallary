# الأمان — إيه اتعمل وإيه لازم تعمله بإيدك

## اتعمل في v1
| المشكلة في النسخة القديمة | الحل |
|---|---|
| أي حساب مسجّل = أدمن (`to authenticated using (true)`) | جدول `admins` ودالة `is_admin()`: الصلاحيات للمسؤولين المحددين فقط |
| أي حد يقدر يبعت آلاف الزيارات/الاستفسارات ويبوّظ الإحصائيات | الإدخال المباشر اتقفل، والتسجيل عن طريق `log_visit` / `log_inquiry` بحد معدّل لكل IP + تحقق من المنتج والكمية |
| رفع الصور لأي حساب مسجّل وبأي نوع/حجم | الرفع للأدمن فقط، وWebP/JPEG/PNG بحد أقصى ٢ ميجا |
| روابط صور غريبة ممكن تتخزن في القاعدة | قيود CHECK على مسار الصورة وأطوال الحقول (+ تحقق في الواجهة) |
| لا يوجد CSP ولا رؤوس أمان | `site/_headers` (CSP صارم، منع الـ iframe، HSTS، إلخ) + CSP احتياطي في `<meta>` |
| كود `onerror` المضمّن (كان هيتعارض مع CSP) | اتشال واتبدل بمعالج أحداث في JS |
| كود لوحة إدارة قديمة (localStorage) جوه الصفحة العامة | اتحذف بالكامل |
| رقم واتساب والاسم محطوطين في الكود | جدول `site_settings`: القراءة للعامة والتعديل للأدمن فقط (`is_admin()`)، وقيود على شكل الرقم وطول الاسم |
| صفحة الإدارة في اسم "سري" فقط | بقت `/admin/` + `noindex` + `no-store`، والحماية الفعلية بتسجيل الدخول و `is_admin()` |

## لازم تعمله بنفسك (خطوات يدوية — مهمة)
1. **شغّل `database/004_security.sql`** (ثم 005 و 006) في Supabase → SQL Editor **قبل** نشر الموقع الجديد.
2. Authentication → Sign In / Providers → Email → **اقفل Allow new users to sign up**.
3. Authentication → Attack Protection → فعّل **CAPTCHA** و **Leaked password protection**.
4. اتأكد من جدول `admins` (Table Editor): لازم يحتوي حسابك إنتِ بس.
5. كلمة سر قوية وفريدة للأدمن، ويفضّل تفعيل MFA للحساب.
6. انشر على استضافة بتدعم `_headers` (Netlify / Cloudflare Pages). على GitHub Pages الـ CSP الاحتياطي بس هيشتغل.
7. لو الدومين اتغيّر: Authentication → URL Configuration → حدّث Site URL.

## حدود معروفة (للشفافية)
- جلسة الأدمن بتتخزن في `localStorage`. الـ CSP الصارم وهروب النصوص بيقللوا خطر XSS كتير، لكن لو عايزة أمان أعلى ممكن نحوّلها لـ `sessionStorage` أو نضيف MFA إجباري.
- الـ Rate limit بيعتمد على IP الزائر؛ الشبكات المشتركة (شركات/جامعات) ممكن تتشارك الحد — الأرقام (١٠ زيارات و٣٠ استفسار في الساعة) محافظة ويمكن تعديلها في `004_security.sql`.
- الـ Publishable key في الكود عام بطبيعته؛ ما تحطيش أبدًا `service_role` / Secret key في أي ملف بالموقع.
- الخطوط من Google Fonts. لاستقلال كامل ونتيجة أفضل في الخصوصية حمّلي Tajawal وAmiri وخدميهم من `/fonts/` وشيلي نطاقات Google من الـ CSP.
